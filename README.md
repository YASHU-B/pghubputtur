# PGHub Puttur

PGHub Puttur is a modern platform to discover PG accommodations, rooms, and rental stays in Puttur for students and working professionals.

## Features

- Browse PGs and rental rooms
- Contact details for owners
- Responsive and user-friendly UI
- Fast and simple navigation
- Mobile-friendly design
- Location-based listings

## Tech Stack

- React / Next.js
- Tailwind CSS
- JavaScript
- Vercel Deployment

## Installation

```bash
git clone https://github.com/YASHU-B/pghubputtur.git
cd pghubputtur
npm install
npm run dev
